## 📖 Description

**Chill Farm** is a 2D farming RPG inspired by games like Stardew Valley. Players manage their own farm — planting seeds, harvesting crops, and building up their land at a relaxed pace. The game focuses on delivering a calm, satisfying gameplay loop with a cozy pixel-art aesthetic.

---

## 🎮 Gameplay

- **Farm management** — plant and harvest crops on your land
- **Day/time cycle** — manage your daily activities within the in-game time system
- **Exploration** — explore the world beyond your farm
- **Progression** — grow and expand your farm over time

---

## ✨ Core Features

- 2D top-down RPG perspective with pixel art visuals
- Farming loop: till soil → plant seeds → water → harvest
- Day/night or time-based cycle system
- Inventory and item management
- Smooth character movement and interaction system
- Custom shaders for visual polish (ShaderLab/HLSL)

---

## ⚙️ Tech Stack

- **Engine**: Unity
- **Language**: C#
- **Art Style**: 2D Pixel Art
- **Rendering**: ShaderLab / HLSL
- **Version Control**: Git

## 🚀 Getting Started

### Download & Play
👉 [https://zussic.itch.io/chill-farm](https://zussic.itch.io/chill-farm)

### Run from Source
```bash
git clone https://github.com/Hoang-hai-yen/ChillFarm.git
```
1. Open Unity Hub → **Open Project** → select the cloned folder
2. Open the main scene → Press **Play**
